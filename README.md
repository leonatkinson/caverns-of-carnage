## Description

This plugin adds a Gutenberg block that creates an interactive form for generating procedural multi-level dungeons. It features:
- Starting dungeon level (difficulty) and level count configuration.
- Client-side procedural generation of rooms, passages, doors, traps, environmental extras, wandering monsters, and scaled treasure hoards.
- Cytoscape.js powered organic topological map rendering.
- Comprehensive adventure manuals with monster stat blocks and interactive hit point tracker checkboxes (`▢ ▢ ▢`).

## Installation

1. Copy the entire plugin folder into `wp-content/plugins`. Alternatively, use `wp-cli` to install the plugin
   like this: `wp plugin install --force https://github.com/leonatkinson/caverns-of-carnage/archive/refs/heads/master.zip`
2. Activate the plugin in WordPress.
3. Place the **Caverns of Carnage Dungeon Generator** block on any page or post.
